MGU RECORDER INSTALLER 1.1.0

Донат можно отправить на карту 2202 2073 7001 1432.

Запустите MGU-Recorder-Installer.exe на Windows 10/11 с .NET Framework 4.6.2
или новее. Подключите ENET и включите MGU. Интернет, Node.js, OpenSSH и права
администратора на ноутбуке для установки не требуются.

1. Выберите приватный SSH-ключ владельца автомобиля. Для зашифрованного ключа
   введите его фразу. Для входа по паролю оставьте поле ключа пустым и введите
   пароль. Локальный стандартный ключ подставляется только как путь к файлу.
2. Нажмите «Проверить». Пустой IP включает поиск MGU через ENET. При первом
   подключении проверьте показанный SSH-отпечаток и подтвердите доверие.
3. После успешной проверки нажмите «Установить». Если требуется перезапуск,
   выполните его отдельной кнопкой после завершения установки.

Для удаления нажмите «Проверить», затем «Удалить» и подтвердите действие.
Удаляются только приложение Recorder и сервер регистратора через mgu-deploy.
Store, mgu-render, mgu-deploy, остальные приложения, записи и настройки архива
в /mnt/share/owner-dvr сохраняются. Шлюз видео сервера для RSE удаляется вместе
с сервером; приложения задних экранов установщик не удаляет. Удаление доступно
и при неисправной камере или недоступном HDD. Старый RESULT установки не нужен.
Удаление продолжается на MGU при потере ENET. После восстановления связи
нажмите «Проверить» для чтения результата. RESULT сохраняет итог удаления
и сведения об ошибке, если удалось удалить только часть компонентов.

MGU Store и SSH — отдельные условия. Этот установщик не включает SSH, не
прошивает и не кодирует автомобиль. Он требует уже работающий SSH и ключ
или пароль, который действительно даёт root-доступ к устанавливаемому MGU.
Наличие Store не означает, что известны данные SSH. При отсутствии доступа
установка остановится до записи в MGU. В комплекте нет универсального ключа,
ключа текущей машины, паролей, VIN или компонентов BMW SDK.

Поддерживается MGU ID7 x86_64 с ICAM2, штатными SOME/IP-интерфейсами и
отдельно смонтированным HDD /mnt/share. Проверка читает каталог конкретного
MGU. ID8 и другая камера не заявлены. Установка на любой VIN возможна внутри
этой аппаратной совместимости; обещания работы на любом оборудовании нет.

В EXE находятся все установочные пакеты:
  Сервер регистратора — owner-dvr 4.1.0
  Приложение Recorder — owner_dvr 1.5.1
  Общие компоненты mgu-store:
    mgu-deploy 0.8.16 — установка и откат
    mgu-render 0.6.19 — вывод интерфейса и видео

Более новые установленные версии сохраняются. Установка использует штатный
mgu-deploy, с проверкой SHA256 и требований, его резервными копиями и откатом.
Исходное приложение связывается с BMW SDK на самом головном устройстве.
Сначала устанавливаются необходимые общие компоненты, затем Core и интерфейс.
Перед записью снова читаются совместимость и текущие версии на MGU.

Шлюз видео для RSE сохранён в Core; приложение задних экранов этот EXE не
устанавливает. Ключ сопряжения создаётся отдельно на каждом автомобиле.
При обновлении существующие настройки, архив и сопряжение сохраняются.

Потеря ENET не убивает уже запущенную установку: работа продолжается на MGU.
Верните связь, запустите EXE и нажмите «Проверить» для чтения результата.
Перезапуск MGU до завершения установки может прервать её. Автоматического
перезапуска нет. Кнопка «Откат» возвращает только приложение/Core регистратора
через mgu-deploy; общие компоненты Store оставляет установленными.

Журнал и RESULT.zip: «Документы\MGU Recorder Installer\RESULT-...». В RESULT
нет введённого пароля и файла приватного ключа. Отпечатки доверенных серверов
и номер последней установки хранятся локально в профиле Windows. Для другого
автомобиля новый/изменившийся SSH-отпечаток требует отдельного подтверждения.

Проверено локально: запуск EXE, загрузка библиотек SSH, SHA256 всех ресурсов,
HSFZ на локальном TCP-стенде, передача через адаптер, версии/совместимость,
порядок установки, отказы до записи, откат и RESULT. Настоящая SSH/SFTP-сессия
и установка этим EXE на автомобиль ещё не проверены. Проверки на машине
родительского проекта не являются проверкой этого установщика.

EXE не имеет цифровой подписи. В отдельном SOURCE.zip находятся исходники
установщика, снимки исходников регистратора/renderer и лицензии. Библиотеки
SSH.NET и зависимости встроены в EXE. Их версии и источники перечислены
в THIRD-PARTY-LICENSES.txt. Сам установщик GPL-3.0-or-later.
