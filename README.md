# MGU Recorder

Видеорегистратор для MGU с BDC2 (G30 дорестайлинг и т.д.)
Требует: MGU ID7, ICAM2, открытого SSH

## Состав

| Компонент | Назначение |
|---|---|
| `owner-dvr` 4.1.0 | Сервер регистратора: захват, архив, воспроизведение, экспорт, шлюз RSE |
| `owner_dvr` 1.5.1 / **Recorder** | Приложение с интерфейсом на экране MGU |
| MGU Recorder Installer 1.1.0 | Windows EXE: установка, проверка, удаление, откат и RESULT |
| `mgu-deploy` ≥0.8.11 | Общий сторонний компонент mgu-store для установки и отката |
| `mgu-render` ≥0.6.19 | Общий сторонний компонент mgu-store для вывода интерфейса и видео |

`mgu-deploy` и `mgu-render` — разработки экосистемы [mgu-store](https://github.com/robertnisipeanu/mgu-store), не собственные компоненты регистратора.

## Исходники и сборка

- [`recorder/`](recorder/) — сервер, интерфейс, собственные C-помощники и тесты.
