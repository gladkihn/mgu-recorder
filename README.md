# MGU Recorder

Независимый регистратор для BMW MGU ID7 с ICAM2 и штатным HDD.

## Возможности

- Непрерывная циклическая запись при включённом зажигании; архив 2/4/8/16 ГиБ.
- Просмотр по времени и цветная шкала поездок без промежутков стоянки.
- Пауза, перемотка на ±1/±10/±60 секунд и режим «Приватность».
- Экспорт на USB до 60 секунд в MP4, до конца записи или границы поездки; временная метка всегда, скорость по выбору.
- Подтверждение экспорта и удаление архива из настроек.
- Один сервер ICAM2 с дополнительным шлюзом видео для отдельно установленного клиента RSE.

## Состав

| Компонент | Назначение |
|---|---|
| `owner-dvr` 4.1.0 | Сервер регистратора: захват, архив, воспроизведение, экспорт, шлюз RSE |
| `owner_dvr` 1.5.1 / **Recorder** | Приложение с интерфейсом на экране MGU |
| MGU Recorder Installer 1.1.0 | Windows EXE: установка, проверка, удаление, откат и RESULT |
| `mgu-deploy` ≥0.8.11 | Общий сторонний компонент mgu-store для установки и отката |
| `mgu-render` ≥0.6.19 | Общий сторонний компонент mgu-store для вывода интерфейса и видео |

`mgu-deploy` и `mgu-render` — разработки экосистемы [mgu-store](https://github.com/robertnisipeanu/mgu-store), не собственные компоненты регистратора.

## Установка

Нужны MGU ID7 x86_64, ICAM2, смонтированный HDD `/mnt/share`, уже установленный mgu-store и работающий root SSH. Установщик не включает SSH, не прошивает и не кодирует блок. Он обнаруживает MGU через ENET; ключ или пароль предоставляет владелец. VIN-привязки нет. ID8 и другие аппаратные конфигурации этой сборкой не заявлены.

1. Используйте собственную сборку установщика и проверьте её SHA256. В текущей публичной публикации распространяются только исходники: готовый EXE и бинарник FFmpeg не опубликованы.
2. Подключите ENET, включите MGU, выберите свой SSH-ключ или введите пароль.
3. Нажмите **Проверить**, подтвердите SSH-отпечаток автомобиля, затем **Установить**.
4. Если Store запросит перезапуск, выполните его после завершения операции.

Более новые общие компоненты сохраняются. Интернет на парковке не нужен. Ключей владельца и BMW SDK в комплекте нет; приложение связывается с SDK на целевом MGU.

## Удаление

После **Проверить** нажмите **Удалить** и подтвердите действие. Удаляются приложение Recorder и сервер через mgu-deploy. Архив и его настройки в `/mnt/share/owner-dvr`, общие компоненты Store и остальные приложения сохраняются. Шлюз видео этого сервера для RSE удаляется вместе с сервером; приложения RSE не удаляются. Удаление доступно и при неисправной камере/HDD, не требует старого RESULT и продолжает выполняться при потере ENET. После восстановления связи нажмите **Проверить**.

## Проверки и ограничения

Сам регистратор ранее проверялся на MGU ID7 с ICAM2. Windows-установщик и деинсталляция версии 1.1.0 проверены локально: ресурсы/контрольные суммы, SSH-библиотеки, ENET-стенд, отказы до записи, порядок установки/удаления, частичные сбои, RESULT, GUI. Установка и удаление именно этим EXE на автомобиле пока не проверены. Другие VIN/прошивки аппаратно не испытаны. EXE не подписан цифровой подписью.
